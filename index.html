BUILT FOR DATA TEAMS

From model files to model understanding

01

Import model definitions

Open a Power BI Project folder with TMDL and optionally PBIR, or import a compatible TMSL/Mapper JSON file. No paid cloud service or sign-in.

02

Navigate the architecture

Explore tables, columns, DAX measure definitions and relationship metadata. Select a table to identify its connected dependencies.

03

Follow report usage

Inspect PBIR report visuals and their explicitly referenced fields. Highlight relevant tables to understand the model footprint of a visual.

04

Document and share

Export an editable Mermaid diagram, vector SVG, Markdown inventory or reusable JSON snapshot.

Good to know: Native .pbix binaries cannot be read directly. In Power BI Desktop, save as a Power BI Project (.pbip), then select the project folder. Field parameter and indirect DAX dependencies require additional analysis and are not claimed to be complete.
BUILT TO BE INSPECTED

Local processing. Visible network activity.

The mapper parses selected files, calculates diagram positions and generates exports locally. It does not transmit model files, DAX expressions or report metadata to a server. The online edition loads Mightora's shared UI, logo and footer dependencies from public hosts. The offline edition bundles scripts and styles without any runtime CDN, API or telemetry.

COMMON QUESTIONS

Frequently asked questions

Can I open a Power BI PBIX file?

Not directly. Export a Power BI Project (PBIP) to get text-based TMDL semantic-model and PBIR report metadata; then import those files or the project folder.

Does the application connect to a Power BI workspace?

No. This edition reads locally selected model definitions and does not require Microsoft authentication or workspace permissions.

Does the model mapper resolve every DAX dependency?

No. It shows direct table and column relationships plus references found in supported PBIR visual metadata. Complex DAX measure chains, calculation groups, field parameters and hidden runtime behaviour need specialist lineage analysis.

Can I edit the diagram after export?

Yes. SVG is a vector format, Mermaid is text-based diagram source, and JSON can be imported back into this mapper.
